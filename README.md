# 5-Star Eco - Round 1 Proposal

Repository này lưu trữ tài liệu Vòng 1 của đội **BDKTN** cho cuộc thi **Vietnamese Student HackAIthon 2026 - Bảng B Challenger**.

## Thư mục nộp chính

Thư mục quan trọng nhất là [`BDKTN`](BDKTN):

- [`BDKTN/proposal.pdf`](BDKTN/proposal.pdf): bản proposal hoàn chỉnh dùng để nộp.
- [`BDKTN/so-do-kien-truc.png`](BDKTN/so-do-kien-truc.png): ảnh sơ đồ kiến trúc hệ thống.

Các nội dung như thông tin đội thi, đặt vấn đề, giải pháp đề xuất, thiết kế tổng quan, phương hướng triển khai, rủi ro và tác động dự kiến đã được trình bày trong file proposal PDF.

## Các file hỗ trợ

- [`proposal-vong-1.md`](proposal-vong-1-template.md): bản nội dung proposal dạng Markdown.
- [`hackaithon-2026-thong-bao-so-1_1780034931.md`](hackaithon-2026-thong-bao-so-1_1780034931.md): bản Markdown của thông báo cuộc thi.
- [`2026_Hackaithon_Proposal`](2026_Hackaithon_Proposal): source LaTeX dùng để dựng proposal PDF.

## Ghi chú

Khi kiểm tra hồ sơ nộp, ưu tiên xem file trong thư mục `BDKTN`, vì đây là thư mục được đặt theo tên nhóm và chứa bản PDF cuối cùng cùng sơ đồ kiến trúc đi kèm.
